# InsightFlow

Cloud-native IoT analytics pipeline using FastAPI, AWS S3, Glue, Athena, and interactive dashboards.

## Features
- IoT data simulation
- ETL validation pipeline
- Dashboard analytics
- Athena SQL querying
- AWS S3 data lake
- Real-time KPI visualization

## Tech Stack
- Python
- FastAPI
- AWS S3
- AWS Glue
- AWS Athena
- Chart.js
